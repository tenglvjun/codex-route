# Repository Agent Instructions

## UI Design System

- All UI design, implementation, and review work in this repository **must follow the design system defined in [`DESIGN.md`](./DESIGN.md)**.
- Treat `DESIGN.md` as the single source of truth for visual tokens, typography, component styling, layout, responsive behavior, motion, content voice, and banned patterns.
- `DESIGN.md` is user-owned and immutable. Never edit, regenerate, reformat, or overwrite it as part of an implementation, review, or automated task.
- Before creating or modifying any UI, read the relevant sections of `DESIGN.md` and reuse its named tokens and interaction rules instead of introducing competing values.
- If a requested UI change conflicts with `DESIGN.md`, ask for an explicit product decision or document the approved exception in the change; do not silently diverge from the design system.
